## 今回のハンズオンの概要

### 作るもの

奈良のまちで見つけた「気になる場所」（石仏・道標・古い町家など、公式の文化財リストに載っていない場所）を LINE で送って残し、あとから近い順に探したり、地図で公式データと見比べたりできる **まちの記憶アーカイブBot** を作ります。サーバーは用意しません。Google スプレッドシートと GAS（Google Apps Script）だけで動きます。

:::message
この資料は、奈良の URBAN DATA CHALLENGE（UDC）とのコラボハンズオン用です。登録する場所は、奈良の場所でなくても構いません。自分の町や、いつもの散歩道で試せます。
:::

| Step | やること |
| :--- | :--- |
| Step1. LINE API基礎編 | Qiita の記事で LINE Bot を作り、おうむ返しで疎通確認する |
| Step2. LINE APIで遊ぶ | 位置情報の受け取り・状態管理・質問に答えて登録・GPS検索を実装する |
| Step3. もくもくタイム | 好きな機能を選んで自由に作り込む |

### 当日の時間割（5時間）

| 時間 | 内容 | 使う資料 |
| :--- | :--- | :--- |
| 0:00–0:10 | 導入 | はじめに・事前準備 |
| 0:10–1:10 | Step1 おうむ返し | Qiita の記事 |
| 1:10–3:30 | Step2（位置情報の受け取り・状態管理・登録・質問シート・GPS検索） | 02章 |
| 3:30–3:40 | 休憩 | — |
| 3:40–4:40 | Step3 もくもく（1〜2個） | 03章 |
| 4:40–5:00 | 振り返り | 感想共有・振り返り |

Step2 の目安は、位置情報の受け取りが20分、状態管理が20分、登録が35分、質問シートが25分、GPS検索が20分、予備が20分です。

### 対象読者

- LINE Bot は作ったことがあるけれど、**何往復かする会話（状態管理）**はまだ、という人
- GAS で**サーバーなしの Bot** を作ってみたい人

## この本の読み方

章のタイトルに付いている絵文字で、その章の性格がわかります。

| 絵文字 | 意味 |
| :--- | :--- |
| 📗 | 読み物。手は動かしません。待ち時間や後日に読んでください |
| 🧭 | **Step2** の章。位置情報・状態管理・登録・GPS検索を作ります |
| 🎖️ | **Step3 もくもく** の章。好きな数だけ、好きな順番で選べます |

Step1 は Qiita の記事で進めるので、この本に手順の章はありません。**Step1 の記事と 🧭 の章が必須**です。ここまで終えると「場所を登録して、GPS で近い順に探せる Bot」ができあがります。

**🎖️ の章はまるごと任意**です。もくもくタイムに、気になるものだけ選んでください。

各章は **手順 → ✅ 確認** の順に並んでいます。`✅ 確認` まで動いたら、次の章に進んで大丈夫です。

:::message
**進み方が人と違っても気にしないでください。** 早く終わった人はもくもくを多めに、詰まった人はゆっくり Step2 まで。それぞれのペースで進めましょう。
:::

## 困ったときは

Gemini・ChatGPT・Claude などの LLM ツールに聞きながら進めて構いません。エラーメッセージを貼って意味を聞いたり、コードを自分の用途に合わせて変えたりするときに頼ると早いです。
